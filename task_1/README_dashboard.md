# Дашборд Taipy «SOC · триаж алертов SIEM»

Интерактивный дашборд по карточкам инцидентов `iavd_incidents_raw`: поток алертов, исходы карточек, скорость реакции, распределения и потоки «категория → вердикт». Под каждым графиком — аналитический вывод с цифрами, который пересчитывается по фильтрам. ML-модель в дашборде не используется.

## Файлы

| Файл | Что внутри |
|---|---|
| `dashboard.py` | приложение Taipy: страницы, фильтры, обработчики |
| `dashboard_data.py` | загрузка parquet, фильтры (период, тип дня, источник, критичность), форматирование чисел по-русски |
| `dashboard_charts.py` | функции «данные → Plotly-фигура», единый стиль и палитра |
| `dashboard_insights.py` | аналитические выводы к графикам |
| `dashboard.css` | оформление страниц |

Положите их в корень проекта рядом с `etl.py` и `main.py`.

## Данные

```
data/agg/features.parquet      # результат etl.py
data/agg/agg_top_src.parquet   # результат etl.py
data/dataframe.parquet         # таблица периодов 7 / 30 / 90 / 180 дней
data/calendar.parquet          # календарь с типом дня
```

## Запуск

Нужен Python 3.12 (для Python 3.13 на PyPI нет свежего Taipy):

```bash
conda create -n idav python=3.12 -y
conda activate idav
pip install "taipy>=4.1" plotly "pandas<3" numpy scipy pyarrow
python dashboard.py
```

Откройте http://localhost:5002. Если `data/agg/features.parquet` ещё нет, сначала выполните `python etl.py --full`.

| Страница | Что на ней |
|---|---|

| О данных | как читать дашборд и оговорки |

## Оговорки по данным

- **Время хранится в миллисекундах** — проверено по разнице дат «Создан» и «Дата взятия в работу».
- **≈28 % карточек берутся в работу «мгновенно»** (< 0,6 с, автоматика). На логарифмической шкале ноль не показать, поэтому они исключены из гистограмм и «скрипок», а их доля указана в выводах.
- **≈23 % карточек без вердикта.** Там, где их много, доли FP и реальных инцидентов занижены.
- **Доля False Positive — решение аналитика по карточке**, а не доля трудозатрат SOC.
- **Топ адресов-источников** — агрегат `etl.py` за весь период, фильтры к нему не применяются.
