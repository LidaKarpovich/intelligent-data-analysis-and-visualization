## 5. Проверка объяснений: подтверждённые и сомнительные кейсы (`5 · Проверка кейсов`)

### Кейс А — объяснение подтверждается данными: `#7 · 521996` (TP)

В исторических данных эксплуатации по 95 % ДИ Уилсона подтверждены **9 из 12** топ-признаков (противоречий: 1). Среди 20 ближайших соседей в пространстве SHAP — **17 из 20** (85 %) реальных инцидентов.

1. **Что видит модель:** В карточке `521996` (TP, факт — реальный инцидент (y = 1), правило `Nad_Possible_Scan_Activity`) модель дала оценку `p = 0,405199` (40,52 %) при пороге `0,0193`; решение — **инцидент (в приоритет)** (запас до порога +3,55 log-odds).
2. **Почему так:** Наибольший вклад дали «Источник — приватный IP (флаг)» *(сконструирован)* = `0` (+2,740), «Частота правила в обучении» *(сконструирован)* = `0.1034` (+1,180), «Текст алерта SIEM» = `Обнаружена сработка правила "SCAN [PTsecurity] z` (+0,842); вклады в логарифме шансов, `base (-8,8524) + Σ (+8,4686) = -0,3838` сходится (`|σ(raw) − p| = 0.0e+00`).
3. **Что делать:** Чтобы исправить поведение модели, возможны: **данные** — сохранять полноту полей `src` и `Алерт` — они обеспечивают 31 % силы верного решения; **порог** — текущий порог работает с большим запасом (+3,55 log-odds); **признак** — сохранить `src_is_private` и частоту правила `freq_Наименование` как устойчивое ядро сигнала. **Выбираю:** **оставить без изменений (эталонный кейс)** — объяснение модели полностью подтверждается статистикой SOC.

## Оговорки

- **SHAP описывает поведение модели, а не физику атаки:** высокий вклад признака не означает причинно-следственной связи с инцидентом.
- **Единицы измерения:** вклады TreeSHAP для LightGBM даны в **логарифме шансов (log-odds)**; сравнивать их напрямую с моделями в вероятностях (например, случайным лесом) нельзя — сравнимы только доли и ранги.
- **Оценка `proba` — модельная оценка, не калиброванная вероятность:** как показано в задании 2, в эксплуатации модель завышает вероятность, а калибровка курсом не проверялась.
- **Сконструированные признаки (`engineered`, 43 из 73):** полей `freq_*`, `len_*`, `cmd_*`, `src_is_private` нет в сырой карточке SIEM — они вычисляются препроцессором и явно помечены в интерфейсе.
- **Порог τ = 0,0193 — часть модели:** в дашборде ручка порога работает в режиме «что если» с обязательным пересчётом матрицы ошибок в шапке.
